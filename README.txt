CAREERFLOW REMODEL - SETUP

1. Extract CareerFlow_Remodel.zip.
2. Open the extracted folder in VS Code.
3. Open index.html with Live Server, or double-click index.html.
4. Choose Get started / Create account to register.
5. Log in using the email and password you registered.
6. Use the sidebar to manage Applications, Interviews, Reminders and Analytics.

FEATURES
- Landing page, login page and signup page
- Dashboard summary
- Add and delete job applications
- Application statuses: Saved, Applied, Review, Interview, Offer, Rejected
- Add and delete interviews with notes and meeting links
- Add and delete reminders
- Basic application, interview and offer analytics
- Responsive layout for desktop and mobile
- Data saved in browser localStorage

IMPORTANT SECURITY NOTE
This is a frontend demo. Accounts and passwords are stored in this browser's localStorage, so this is NOT secure authentication and accounts do not sync across devices. For a real public website, connect a backend/auth provider (for example Firebase or Supabase) and a database. Do not use real passwords in this demo.
